## Vor Etsy-Upload

1. Jede SVG in Canva/Kittl/Inkscape oeffnen.
2. Export als PNG mit transparentem Hintergrund.
3. Zielgroesse: 4500 x 5400 px.
4. Auf schwarzem, weissem und grauem Shirt testen.
5. DPMA/EUIPO/TMview/Etsy/Google Check durchfuehren.
6. Mockups erstellen.
7. Erst danach Status auf `QC Approved` setzen.

## Wichtig

Diese Designs sind bewusst generisch und verwenden keine Marken, Logos, Promis, Film-/Serien-/Game-Namen oder Vereinsreferenzen. Trotzdem muss vor Veroeffentlichung ein echter Markencheck gemacht werden.
