# Rechts- und Qualitaetskontrolle

Diese Checkliste ist das Gate vor jeder Veroeffentlichung. Sie ist keine Rechtsberatung, aber ein praktischer Mindeststandard fuer risikoarme POD-Listings.

## 1. Harte Ausschlusskriterien

Ein Design darf nicht online gehen, wenn es eines davon enthaelt:

- Markenname
- Logo
- Prominame
- Film-, Serien- oder Spieletitel
- erkennbare Figuren, Maskottchen oder Charaktere
- Fussballverein oder Vereinswappen
- Songtext oder bekanntes Zitat
- "inspiriert von [Marke/Film/Game]"
- Nachahmung eines bekannten Markenstils
- geschuetzte Slogans
- KI-Wasserzeichen oder fremde Signaturen

## 2. Rechtscheck-Routine

Fuer jeden Spruch und jedes Motiv:

1. DPMAregister suchen
2. EUIPO eSearch/TMview suchen
3. Etsy-Suche durchfuehren
4. Google-Suche mit Anfuehrungszeichen durchfuehren
5. Pruefen, ob der Spruch stark mit einer Marke, Person, Serie, einem Song oder Verein verbunden ist

### Suchformate

```text
"[SPRUCH]"
"[SPRUCH]" shirt
"[SPRUCH]" trademark
"[SPRUCH]" marke
"[SPRUCH]" etsy
```

## 3. Risikobewertung

| Risiko | Bedeutung | Entscheidung |
|---|---|---|
| niedrig | Generischer Alltagsspruch, kein Markenbezug | kann in QC |
| mittel | Spruch haeufig genutzt, unklarer Ursprung | ueberarbeiten oder genauer pruefen |
| hoch | Marken-/Popkultur-/Promi-/Franchise-Naehe | nicht verwenden |

## 4. Design-QC

- [ ] PNG transparent
- [ ] 4500 x 5400 px oder vergleichbar druckfaehig
- [ ] Text korrekt geschrieben
- [ ] Umlaute korrekt oder bewusst ASCII
- [ ] gute Lesbarkeit auf Schwarz
- [ ] gute Lesbarkeit auf Weiss
- [ ] gute Lesbarkeit auf Haupt-Shirtfarbe
- [ ] keine abgeschnittenen Elemente
- [ ] keine KI-Artefakte
- [ ] keine falschen Haende/Gesichter/Objekte bei Illustrationen
- [ ] keine feinen Linien, die im Druck verschwinden
- [ ] Motiv mittig
- [ ] Druckbereich passend
- [ ] maximal 2-4 Hauptfarben
- [ ] keine Fremdsignatur oder Wasserzeichen

## 5. Mockup-QC

- [ ] Hauptbild zeigt Produkt und Design klar
- [ ] kein irrefuehrendes Premium-Produkt, wenn Standardshirt verkauft wird
- [ ] Shirtfarbe im Mockup ist tatsaechlich kaufbar
- [ ] Designgroesse wirkt realistisch
- [ ] keine abgeschnittenen Mockup-Raender
- [ ] Groessentabelle vorhanden
- [ ] mindestens 3 Bilder
- [ ] keine Marken im Hintergrund
- [ ] keine fremden Logos sichtbar

## 6. Listing-QC

- [ ] Hauptkeyword im Titel
- [ ] Titel natuerlich lesbar
- [ ] 13 Tags vorhanden
- [ ] keine verbotenen Markenbegriffe in Titel/Tags/Beschreibung
- [ ] Beschreibung erklaert Produkt korrekt
- [ ] POD-Hinweis vorhanden
- [ ] Pflegehinweise vorhanden
- [ ] Groessenhinweis vorhanden
- [ ] Versand-/Produktionshinweis ohne falsche Garantien
- [ ] Preis und Marge geprueft
- [ ] Produktvarianten korrekt

## 7. Freigabeentscheidung

```text
PASS:
Design ist rechtlich unauffaellig, druckfaehig und listingbereit.

PASS MIT AENDERUNGEN:
Kleine Aenderungen erforderlich, z.B. Kontrast, Schreibweise, Mockup, Tags.

FAIL:
Rechtsrisiko, schlechte Druckbarkeit, falsche Produktdaten oder unklare Herkunft.
```

## 8. Veroeffentlichungsregel

Der Status darf nur von `QC Review` auf `Etsy Draft` wechseln, wenn:

- Rechtscheck abgeschlossen
- Design-QC bestanden
- Listing-QC bestanden
- Mockup-QC bestanden
- Marge geprueft

Der Status darf nur von `Etsy Draft` auf `Live` wechseln, wenn eine Person die finale Etsy-Vorschau geprueft hat.

## 9. Skalierungs-QC fuer 50-200 Listings/Tag

Bei hoher Menge:

- Rechtscheck batchweise vor Designproduktion
- gleiche Nische nicht unendlich duplizieren
- 10 Prozent der Listings stichprobenartig erneut pruefen
- alle abgelehnten Claims dokumentieren
- keine automatische Live-Schaltung ohne Freigabe
- Design- und Listing-Duplikate erkennen
